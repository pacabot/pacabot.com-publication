Code source de Zhonx III

Après avoir quasiment fini la conception mécanique et électronique, nous passons maintenant à la conception du code informatique du robot.

Pour pouvoir travailler en groupe, nous avons créé un dépôt git sur Google Code. En allant dedans, vous allez pouvoir voir et télécharger l’intégralité et la dernière version du code faisant fonctionner la petite merveille.

Adresse du dépôt : code.google.com/archive/p/zhonx3
